# Get Started

!!! info "Status: Live (reproduced 2026-05-23)"
    Verified against examon-core v0.5.0.

> The Get Started section is the universal entry point: a 30-second identity, a 15-minute canonical install, the five concepts every reader needs, and a funnel into the three audience guides. A reader who has just landed on the site and does not yet self-identify as Administrator, User, or Developer starts here.

## In this section

- [**What is ExaMon**](what-is-examon.md) — the 30-second identity. What ExaMon is, what problem it solves, what is shipped today, who it is for.
- [**Quickstart**](quickstart.md) — a 15-minute path from zero to seeing real data on a local Kubernetes cluster (K3d) using the scripts shipped in the repository.
- [**Core concepts**](core-concepts.md) — the five concepts every reader needs before going deeper: schema-less time series, MQTT decoupling, the SQL federation layer, YAML-defined collectors, and the composable, opt-in nature of the platform.
- [**Where next**](where-next.md) — the branch point into Administrators, Users, Developers, Concepts, Reference, and Community.

## A suggested order

A first-time reader who has 30 minutes:

1. Read [What is ExaMon](what-is-examon.md) — 5 minutes.
2. Read [Core concepts](core-concepts.md) — 5 minutes.
3. Run the [Quickstart](quickstart.md) — 15 minutes.
4. Use [Where next](where-next.md) — 5 minutes — to pick the next destination.

A reader who already knows what ExaMon is and only wants to install it can skip directly to the [Quickstart](quickstart.md), or to the [Administrators → Deploy](../administrators/deploy/index.md) section for the production paths.

A reader who only wants to understand the architecture, without installing anything, can skip directly to [Concepts → Architecture](../concepts/architecture.md).
