# Concepts

!!! warning "Status: Spec — section under development"
    Implementation tasks are listed at the bottom.

> The Concepts section is the universal explanation surface: longer-form than the get-started pages, but cleanly separated from the procedural guides. It is for evaluators, the curious, and future maintainers who want to understand *how* and *why* ExaMon is shaped the way it is, independent of any single install path.

## In this section

- **Architecture** — the stack and the data pipeline.
- **Composable deployment** — the two shapes (Deploy and Plug-in) and why.
- **Data model** — schema-less time series, tags, structured data.
- **Plugin model** — how SDK v3 thinks about ETL.
