# Concepts

!!! info "Status: Live (reproduced 2026-05-23)"

> The Concepts section is the universal explanation surface: longer-form than the get-started pages, but cleanly separated from the procedural guides. It is for evaluators, the curious, and future maintainers who want to understand *how* and *why* ExaMon is shaped the way it is, independent of any single install path.

## In this section

- [**Architecture**](architecture.md): the stack and the data pipeline, layer by layer.
- [**Data model**](data-model.md): schema-less time-series, the canonical tag set, MQTT topic anatomy, and the structured-data path.
- [**Plugin model**](plugin-model.md): how SDK v3 thinks about ETL, the worker pool, restart semantics, and concurrency modes.
