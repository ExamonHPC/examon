# Reference

> The Reference section is universal lookup: terse, complete, alphabetized where useful. It is for readers who already know what they need and want the canonical answer (a flag, a YAML key, a metric name, a tool ID) without prose.

## In this section

- **Component catalog** — every component, version, status, source repository.
- **Helm values reference** — the chart `values.yaml` surface.
- **KairosDB REST** — endpoints, query syntax, examples.
- **MQTT topics** — broker topic conventions used by publishers.
- **Trino SQL** — schema, functions, ExaMon-specific extensions.
- **AI tools** — the tool surface exposed by ExaMon AI.
- **Inventory schema** — `inventory.yaml` reference for the fleet scheduler.
- **Glossary** — terms used across the site.
